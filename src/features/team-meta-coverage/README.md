# Team Meta Coverage

Agrega tres matrices 1v1 existentes para medir cobertura colectiva sin simular
un combate táctico 3v3. `domain` no depende de React, `application` coordina el
runner del meta, `storage` conserva únicamente resultados compactos compatibles,
y `components`/`hooks` contienen la experiencia de usuario.

Las versiones de esquema, motor y meta forman parte de la clave de compatibilidad.
